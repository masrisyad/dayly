# Bahasa (i18n)

Kode: `src/i18n/`.

- `en.ts` adalah kamus sumber. Tipenya (`Dict`) mewajibkan bahasa lain punya kunci yang sama.
- `id.ts` adalah Bahasa Indonesia.
- `index.tsx` berisi `I18nProvider` dan hook `useI18n()` yang mengembalikan `{ lang, t, setLang, date }`.

## Pemakaian

```tsx
const { t, date } = useI18n();
t.daily.title;                                    // teks biasa
fmt(t.home.completed, { n: 40 });                 // placeholder {n}
date('2026-10-24', { weekday: 'long', day: 'numeric' }); // format tanggal sesuai bahasa (Intl)
```

## Pemilihan bahasa

1. Jika profil sudah ada, bahasa diambil dari `profile.lang`.
2. Jika belum (sebelum onboarding), bahasa mengikuti browser: `id*` → Indonesia, selain itu English.
3. Mengganti bahasa di onboarding/Pengaturan langsung tersimpan ke profil.

Teks yang sengaja **tidak** diterjemahkan: nama aplikasi, label "My" + "Daily Planner" di halaman Harian (bagian dari desain), dan footer kredit.

## Menambah bahasa

1. Salin `en.ts` menjadi, misalnya, `ms.ts`, lalu terjemahkan semua nilainya (TypeScript akan memberi tahu kunci yang terlewat).
2. Tambahkan kodenya ke tipe `Lang` di `src/db/db.ts`.
3. Daftarkan di `dicts` pada `src/i18n/index.tsx`.
4. Tambahkan pilihan di `LangSwitch` (`src/pages/Onboarding.tsx`).
5. Catat di [CHANGELOG.md](CHANGELOG.md) dan perbarui panduan bila perlu.
