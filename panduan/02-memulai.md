# 2. Memulai: Profil & PIN

## Layar sambutan

Saat pertama kali dibuka, Dayly menampilkan **Selamat datang di Dayly**. Isi:

| Isian | Keterangan |
|---|---|
| **Nama kamu** | Wajib. Dipakai untuk sapaan, misalnya "Selamat pagi, Maya!" |
| **Foto (opsional)** | Ketuk **Pilih foto**. Foto otomatis dipotong persegi. Tanpa foto, avatar memakai gambar beruang |
| **Bahasa** | **Indonesia** atau **English** |
| **Kunci PIN (opsional)** | 4–6 angka. Jika diisi, ulangi di **Ulangi PIN** |

Ketuk **Mulai** untuk masuk ke Beranda.

Pindah dari HP lain? Ketuk **Pindah dari perangkat lain? Impor backup** dan pilih file backup-mu. Lihat [Backup & pindah HP](07-backup-dan-pindah-hp.md).

## Kunci PIN

Jika PIN aktif, setiap kali Dayly dibuka akan muncul layar **Masukkan PIN**.

- Ketik PIN di keypad. Dayly terbuka otomatis begitu PIN benar.
- Jika PIN salah, ketuk **OK** (atau ketik sampai 6 angka) dan akan muncul pesan "PIN salah, coba lagi."
- **⌫** menghapus satu angka.
- Saat HP dimiringkan (landscape), keypad tampil di sisi kanan.

### Lupa PIN?

PIN tidak bisa dipulihkan. **Lupa PIN?** akan **menghapus semua data** di perangkat ini (ada dua kali konfirmasi), lalu Dayly kembali ke layar sambutan.
Jika kamu punya file backup, kamu bisa mengimpornya lagi setelah itu.

> PIN hanya mengunci tampilan aplikasi. Data di perangkat tidak dienkripsi.

PIN bisa dipasang, diganti, atau dihapus kapan saja di [Pengaturan](06-pengaturan.md).
