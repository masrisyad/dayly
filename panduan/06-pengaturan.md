# 6. Pengaturan

Buka lewat tab **Pengaturan** di menu bawah.

## Profil

- **Ganti foto** / **Hapus foto**.
- **Nama**: ketuk lalu ubah. Tersimpan otomatis.
- **Bahasa**: **Indonesia** atau **English**. Tampilan langsung berganti.

## Kunci PIN

- **Pasang PIN** (jika belum ada) atau **Ganti PIN**: isi PIN baru 4–6 angka dua kali, lalu ketuk **Simpan**.
- **Hapus PIN**: mematikan kunci.
- PIN baru mulai diminta saat Dayly dibuka berikutnya.

Lihat juga [Kunci PIN](02-memulai.md#kunci-pin).

## Data & backup

- **Unduh data**: membuat file backup. Lihat [Backup & pindah HP](07-backup-dan-pindah-hp.md).
- **Impor data**: memulihkan dari file backup. Semua data di perangkat ini akan **diganti**.
- **Amankan data → Aktifkan**: meminta browser agar tidak menghapus data Dayly saat ruang penyimpanan menipis. Jika browser menolak, memasang Dayly ke layar utama biasanya membantu.

## Pasang Dayly

Instruksi memasang Dayly ke layar utama, jika belum terpasang.

## Tentang

- Versi aplikasi (misalnya **Versi 1.0.0**).
- **Hapus semua data**: menghapus seluruh data Dayly di perangkat ini, lalu kembali ke layar sambutan. **Tidak bisa dibatalkan.** Unduh backup dulu jika masih perlu.
