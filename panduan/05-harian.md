# 5. Harian

Halaman **Harian** ("My Daily Planner") adalah planner lengkap untuk satu hari. Buka lewat tab **Harian**, kartu Sekilas Hari Ini, atau tanggal di kalender Beranda.

Semua isian **tersimpan otomatis** sekitar setengah detik setelah kamu berhenti mengetik. Tidak ada tombol simpan.

## Pilih tanggal

- Ketuk **kertas tempel bertuliskan tanggal** di pojok kanan atas untuk memilih tanggal dari kalender.
- Atau ketuk **‹** / **›** untuk hari sebelumnya/berikutnya.
- Tombol **Hari ini** muncul jika kamu sedang melihat tanggal lain.

## Bagikan

Ketuk **Bagikan** di bawah navigasi tanggal untuk membagikan hari ini sebagai gambar. Kamu bisa memilih bagian mana saja yang ikut. Lihat [Bagikan sebagai gambar](10-bagikan-gambar.md).

## Bagian-bagian

| Bagian | Cara pakai |
|---|---|
| **Prioritas Utama** | Tiga hal terpenting hari ini. Setelah diisi, muncul ♡ untuk menandai selesai. Prioritas ikut tampil di Beranda dan dihitung dalam progres |
| **Daftar Tugas** | Sama seperti di [Mingguan](04-mingguan.md): ketik lalu Enter untuk menambah, ♡ untuk selesai, ✕ untuk hapus. Bisa dipakai di hari apa saja, termasuk Sabtu & Minggu |
| **Jadwal** | Isi kegiatan per jam dari **09:00 sampai 20:00**. Seluruh jadwal ini juga tampil di Sekilas Hari Ini di Beranda |
| **Pengingat** | Catatan singkat yang perlu diingat. Ketik lalu Enter untuk menambah, ✕ untuk menghapus. Tidak ada notifikasi |
| **Pelacak Air** | 8 gelas. Ketuk gelas ke-N untuk mengisi sampai gelas itu. Ketuk gelas terakhir yang terisi untuk mengurangi satu |
| **Catatan** | Tulis apa saja dengan bebas |

## Di tablet / layar lebar

Halaman Harian tampil dalam 2 kolom seperti planner kertas.
