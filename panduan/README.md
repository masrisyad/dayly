# Panduan Pengguna Dayly

Dayly adalah planner harian & mingguan yang bisa dipasang di HP dan dipakai tanpa internet.
**Semua data tersimpan di perangkatmu sendiri.** Tidak ada akun dan tidak ada server.

Buka aplikasinya di: **https://masrisyad.github.io/dayly/**
